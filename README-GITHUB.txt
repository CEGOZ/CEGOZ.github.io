# CEGOZ — GitHub Pages

Exportación estática de Framer preparada para probar en GitHub Pages.

## Publicación
1. Sube el contenido de esta carpeta a la raíz del repositorio `CEGOZ.github.io`.
2. Mantén `index.html` en la raíz.
3. En GitHub, abre Settings → Pages.
4. En Build and deployment, elige Deploy from a branch → `main` → `/ (root)` → Save.

## Rutas
- `/`
- `/study/`
- `/mini/`
- `/sobre-cegoz/`
- `/mini-portfolio/`
- `/mini-comparador/`
- `/study-prueba/`

## Importante
Esta exportación conserva HTML generado por Framer y depende de recursos externos alojados en `framerusercontent.com`.
No es el proyecto editable original de Framer. Hay que probar navegación, fuentes, imágenes, formularios y cualquier función interactiva tras publicarlo.
